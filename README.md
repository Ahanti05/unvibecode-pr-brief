# UnvibeCode PR Brief (prototype)

Turns an UnvibeCode review into one short comment on a pull request:
workflows touched, files to review first, and a low/medium/high label.

Prototype only. It is not an official UnvibeCode tool.

## Try it
1. `python -m unvibecode review --repository <repo> --output out`
2. `python pr_brief.py --results out/<analysis-folder> --changed src/a.py src/b.py`

## Example output
Real output from a review of [pallets/flask](https://github.com/pallets/flask) (commit `49943b5`, UnvibeCode 0.4.0),
pretending a pull request changed `src/flask/helpers.py`:

```
python pr_brief.py --results out/flask-unvibecode-analysis-<time> --changed src/flask/helpers.py
```

This is the comment it produces:

> ## UnvibeCode PR Brief  `unvibecode: high-risk`
>
> 1 file(s) changed, 1 found in the Connected Code Map.
>
> **Business workflows touched**
> - Register a blueprint and its routes with an application / Serve files from a blueprint's configured static dir
>
> **Review these files first** (they depend on the changed code)
> - `src/flask/__init__.py` (11 links)
> - `src/flask/app.py` (6 links)
> - `src/flask/cli.py` (3 links)
> - `examples/tutorial/flaskr/blog.py` (3 links)
> - `examples/tutorial/flaskr/auth.py` (3 links)
> - `src/flask/sansio/app.py` (3 links)
> - `src/flask/blueprints.py` (2 links)
> - `src/flask/templating.py` (2 links)
>
> **The changed code relies on**
> - `src/flask/wrappers.py`
> - `src/flask/typing.py`
> - `src/flask/globals.py`
> - `src/flask/signals.py`
> - `tests/conftest.py`
>
> _Risk label rule: dependents + 3 x workflows touched; docs/tests-only = low. Generated by UnvibeCode._

## What it uses
- `connections.jsonl` (from the results ZIP): who imports whom
- `business-workflows.html`: which workflow references which file

## Known limits
- The risk label is a simple rule (dependents + 3 x workflows touched), not a security verdict.
- Links come from UnvibeCode's map, so wrong links in the map show up here too
  (for example it listed `tests/conftest.py` as a dependency of `src/flask/helpers.py`).
- The GitHub Action file is untested on GitHub. It reviews the PR branch only, with no base-branch cache yet.
- Python standard library only.
